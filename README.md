# LeanLens

LeanLens is a video monitoring platform with AI analysis and ERP integration. It helps improve productivity, reduce waste, and enhance workplace safety using computer vision and machine learning.

## Repository structure

| Component | Path |
|-----------|------|
| Backend (Django API) | `LeanLens-backend-main/5s-backend-main/` |
| Frontend | `LeanLens-frontend-main/5s-frontend-main/` |
| Web server | `LeanLens-webserver-main/5s-webserver-main/` |
| Algorithms controller | `LeanLens-algorithms-controller-main/5s-algorithms-controller-main/` |
| Control manual | `LeanLens-control-manual-main/5Scontrol-manual-main/` |

Each component includes its own README with setup and deployment instructions.

## Getting started

Refer to the README in each component directory for environment setup, dependencies, and run instructions.
