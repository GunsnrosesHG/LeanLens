# LeanLens — Cleanup Plan (what we can delete, when)

> **Status: PLAN ONLY — nothing has been deleted.** Every wave is opt-in and
> ordered by risk. Run each wave as its own step so it can be audited; Wave 3
> touches git and needs a commit. Sizes measured on this machine (Oct 2026).

---

## Wave 1 — safe now (local disk only, everything here is git-ignored)

Zero effect on the platform, on git, or on the submission archive.

| Item | Size | Action | Restore if needed |
|---|---|---|---|
| Root build transcripts: `.build-all.log`, `algo_build2.log`, `compose_pull.log`, `docker_build.log` | 364 K | `rm *.log .build-all.log` | never (history in `docs/ACCOMPLISHMENTS.md`) |
| Upstream source zips: `LeanLens-{backend,frontend,webserver,control-manual,algorithms-controller}-main.zip` | 30 M | `rm LeanLens-*-main.zip` | re-download from 5sControl (extracted trees **are** committed) |

| `frontend/node_modules/` | **409 M** | only under disk pressure | `cd frontend && npm ci` (~2 min) |

**Wave 1 total ≈ 30 M** (440 M if `node_modules` is included).

## Wave 3 — repository cleanup (needs a git commit)

Ordered by value; each is independently shippable.

1. **Remove the legacy ERP dumps from git**
   `git rm -r LeanLens-backend-main/backend-main/dumps/` → **97 M** off the
   working tree. Verified: no code references them (only `json.dumps` matches).
   Note: git history keeps the blobs; a true purge needs a history rewrite +
   force-push — only worth it before the jury clones, otherwise skip.
2. **Retire the legacy CRA UI** (rollback fallback — only after the v2 UI is
   accepted): delete the `front` service from `docker-compose.pfe.yml`, the
   commented rollback lines in `nginx/default.conf`, the
   `LeanLens-frontend-main/` extraction (2.5 M) and the local
   `leanlens/front` image (**2.29 G** reclaimed). Update README rollback note.
3. **Retire `algorithms-controller`** (optional): remove the service from
   compose and the `/api/algorithms/` nginx location; delete
   `leanlens/algorithms-controller` image (**1.13 G**). It crash-loops today
   and the platform already bypasses it — verify the UI's Algorithms page
   first (its list endpoints go through Django, not the controller).
4. **Agent-tooling folders** (`.claude/`, `.claude-flow/`, `.swarm/`,
   `CLAUDE.md`, `.mcp.json`, `claude-flow.config.json`) — already git-ignored;
   delete from disk only if those tools are no longer used (2.3 M).
5. **Drop the `extras` profile service** `onviffinder` from compose if camera
   discovery stays Windows-excluded (19.5 M image) — low value, low gain.

**Wave 3 total ≈ 97 M (git) + up to 3.4 G (Docker images/local trees).**

## Never delete

| Path | Why |
|---|---|
| `models/best.pt` | model server reads it at runtime (mounted read-only); committed |
| `docker-compose.pfe.yml`, `nginx/default.conf` | the platform's definition |
| `frontend/src/`, `algorithm/src/`, `LeanLens-backend-main/` (extraction) | the product source |
| `training/data/images/test/coco_{292488,545100,411754}.jpg` | `fake-camera` mounts them (committed for this reason) |
| `docs/` (report, deck, screenshots, `ACCOMPLISHMENTS.md`) | submission materials |
| `.freebuff/` | **required by the Freebuff app** (project id) — never touch |
| `volumes/` **while the stack runs** | live PostgreSQL/evidence data — wiping it destroys the demo DB (reset is possible: see RUNNING.md §13) |
| `.jwt-token` deletion is fine, but never *commit* it | secret (already git-ignored) |
